## 未进入的主要内容

重新抽取的候选里，大量是**陕甘根据地/西北红军的连片叙事**（1932-1933 年照金根据地、陕甘游击队、红二十六军组建、习仲勋相关活动等），这类内容在游戏里有连续文本，但未进入项目数据。示例：

- 1932-05 陕甘游击队粉碎"进剿"，转战5县连打9仗
- 1932-12 陕甘游击队改编为红二十六军
- 1933-03 陕甘边特委成立，习仲勋任军委书记
- 1933-04 陕甘边革命委员会成立

这些属于游戏叙事，按项目纪律**不能自动当史实**，需要用权威党史来源复核后才能正式进入。

## 为什么只导入 246 条

README 与 `tools/import_steam_timeline.py` 记录了当初的编辑决策：从候选中"筛选并改写 246 条"，只保留可被策展叙事承接的部分，且全部压低确定性。这是有意的克制，不是遗漏 bug。
