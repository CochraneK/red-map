# Provenance Status

This file tracks publication-relevant provenance **without pretending unresolved material is cleared**.

## Source layers

### Structured public sources

`data_edit/sources.csv` registers the source ids referenced by events, persons, exhibits and artifacts. The build pipeline rejects unknown ids.

A registered source is traceability metadata, not automatic proof that every interpretation is correct. Human review still decides whether a source supports the specific claim.

### Extracted game material

Source id `src_steam_longmarch_1934_1936` represents locally extracted third-party game text.

Policy:

- raw extraction: private/ignored only;
- public repository: short rewritten candidate entries only;
- game-only support: `certainty=low`;
- promotion above low certainty: add independent evidence and review the claim;
- do not republish long original game passages.

### Visual assets

`data_edit/visual_assets.csv` tracks image page, credit and license fields.

**As of 2026-11-24 (v32) the external-asset debt is cleared.** All 38 external rows now carry an exact per-file license (`CC BY-SA 3.0` / `CC BY-SA 4.0` / `CC0` / `Public domain`) and an exact attribution string (`<author> / Wikimedia Commons`, including the `Unknown author (uploaded by <uploader>)` and `Chinese government` forms where the file page states no author). Values were fetched programmatically from the Wikimedia Commons API (`prop=imageinfo&iiprop=extmetadata|user`), not hand-copied, so they can be re-verified at any time.

`tools/check_project.py::check_visual_asset_provenance` is now a **hard gate**: a generic value such as `see file page`, `unknown` or `tbd`, or a missing credit, fails the build instead of emitting a warning.

Remaining obligations for redistribution or commercial use:
1. keep the `imagePageUrl` as the authoritative provenance record for every asset;
2. keep attribution text next to the image wherever it is displayed;
3. for `CC BY-SA` assets, preserve the share-alike terms of any derivative work;
4. re-run the resolver if an upstream file page changes license or author.

Project-authored screenshots marked `license=project asset` remain a separate category with no external page.

### Historical place names

`data_edit/gazetteer.csv` is the canonical place-name layer: one row per normalized `locationName`, with province, historical/modern name aliases, median coordinates, event count, forces involved, and — for 53 ambiguous names — an explicit disambiguation note (e.g. which "两河口" hosted the 1935 conference, that "安定" in Shaan-Gan documents means today's Zichang rather than Gansu's Anding district). The gazetteer is regenerated by `tools/build_gazetteer.py` on every pipeline run and validated by `check_gazetteer_integrity`.

## Private research boundary

The following paths are intentionally excluded from public Git:

- `research_private/`
- `steam_text_dump/`
- generated test/browser artifacts

CI checks that private research directories have not accidentally become tracked files.
